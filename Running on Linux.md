For my fellow Linux users,
Running the calculator app without WINE translation is quite convenient, so i decided to start including the Linux executable file just for that reason  
How to Run:
1) Navigate to the folder you downloaded the calculator app into, then press Ctrl + . , to open the terminal (or else right click and open in terminal)  
2) Then copy this into the newly opened window, "chmod +x Calculator\ V2.0.0", hit enter and then copy this to the terminal: "./Calculator\ V2.0.0". For your convince, i will manually update these commands to support the latest version available for Linux.  
That's it, once you are done simply close the terminal, and in the folder containing the calculator app, the logs file will be present.
Thank you.
