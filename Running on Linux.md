For my fellow Linux users,
Running the calculator app without WINE translation is quite convenient, so i decided to start including the Linux executable file just for that reason  
How to Run:
1) Navigate to the folder you downloaded the calculator app into, then press Ctrl + . , to open the terminal (or else right click and open in terminal)  
2) Then copy this into the newly opened window, "chmod +x Calculator\ V2.0.1.bin", hit enter and then copy this to the terminal: "./Calculator\ V2.0.1.bin". For your convince, i will manually update these commands to support the latest version available for Linux (for older versions replace the 3 numbers after 'V' with the numbers in your file).
Note: for Linux BETA, run "chmod +x Calculator \BETA\ release.bin", followed by, "./Calculator\ BETA\ release".
That's it, once you are done simply close the terminal, and in the folder containing the calculator app (most likely the downloads folder), the logs file will be present.
Thank you.
